01 · Flagship · Distill Software LLC

Distill turns open textbooks into
interactive courses.

Distill starts with openly licensed textbooks that I curate and rebuilds each one as a complete course. Every chapter is distilled into concepts, each with clear explanations, figures, and practice questions, and everything is scheduled for long-term review with FSRS spaced repetition. Students simply pick a ready-made course from the catalog and start studying.

Behind it is a Python pipeline I built from scratch. Each book is extracted from its PDF, mapped into concepts, and run through multi-pass LLM generation, producing 500 to 1,000 practice questions per textbook. Every result is validated before it lands in PostgreSQL.

The part I am proudest of is the blind-solve gate: an independent model must re-derive every computed answer before a question ships. That one check took wrong answer keys from 1.4 percent to zero across roughly 2,000 audited questions.

Visit studydistill.com Founded March 2026 · Live in production

The content pipeline

  1. Curatean open textbook chosen for the catalog
  2. Extractpages to markdown and figures
  3. Mapchapters into discrete concepts
  4. Generateexplanations and questions, multi-pass
  5. Verifyblind-solve gate re-derives every computed answer
  6. Studyinteractive course with spaced repetition

Verified by design

Generated content is fact-checked against the source text, and computed answers pass an independent blind-solve check before students ever see them.

Built to retain

FSRS spaced-repetition scheduling decides what each student reviews and when, so studying compounds instead of evaporating.

Feels like a game

XP, streaks, study pets, and leaderboards make finishing a chapter something students want to do again tomorrow.

Run like a product

Stripe handles billing, the app installs as a PWA, and I operate the production infrastructure across Vercel, Railway, and Neon.
